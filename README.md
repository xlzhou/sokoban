# 推箱子物语 📦

一个移动端优先的推箱子（Sokoban）网页游戏，**单文件实现**——整个游戏只有一个 `index.html`，无需构建、无需依赖，打开即玩。

## 玩法

- 把所有箱子 📦 推到发光的目标点上即可通关
- 箱子只能推、不能拉，进死角就拉不回来了
- 共 **15 关**，从入门到硬核，关关经过程序化验证可解

## 操作

| 操作 | 方式 |
|---|---|
| 移动 | 方向键 / WASD / 屏幕方向键 / 滑动手势 |
| 撤销 | `Z` / `U` 键，或点「↶ 撤销」按钮 |
| 重开 | `R` 键，或点「↺ 重开」按钮 |
| 关卡切换 | 顶栏「‹ / ›」按钮 |

## 特性

- 📱 移动端适配：触屏手势 + 安全区适配 + 自适应画布
- 🎨 Canvas 手绘风格：四朝向精细化人物（红帽搬运工）、动画插值
- 🔊 Web Audio 合成音效（移动 / 推箱 / 通关旋律，可静音）
- 💾 localStorage 最佳成绩存档（每关独立记录）
- ↩️ 无限撤销，随时反悔
